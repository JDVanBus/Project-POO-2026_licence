# Proyecto 2026-1: Webscrapping Startup 
> Documentación oficial del proyecto de POO 2026-1, webscrapping en python a traves del paradigma OO

De las grandes maravillas que ha traido el siglo XXI ha sido el acceso a la información; sin embargo tambien ofrece una contraproducción, pues su abismalidad 
abruma y desoirienta la veracidad y calidad de está información

No solamente cómo solución, sino cómo herramienta cotidiana de filtración de información, se inició el desarrollo de una clasificación de datos visibles o no en la red , especialmente en aquellos casos donde buscamos
información muy específica y facilmente obtenible.

A partir de esto, nace a la luz el webscrapping, entendido cómo la *técnica automatizada para exraer y estructurar grandes cantidades de datos no estructurados, para su analísis*.
en servidores web.compuesto en tres procesos principales:


| proceso | descripción | 
|---------|-------------|
| Extracción de datos | petición de información al servidor usando el built-in "request" | 
| Organizar información | clasificar y dividir información para extraer solo la relevante, tambien llamado "parsear" datos |
| Procesar y Almacenar | busca dar un analisis específico a la información requerida, para luego almacenarla |

El webscrapping tiene cómo fin automatizar la busqueda ordenada de información grande, que determine procesos, resuelva problemas y lleve a cabo decisiónes 
a partir de esta.

## Definición del proyecto

A partir de las necesidades básicas que requiere toda adquisición de información, se propone el siguiente enunciado:

*Desarollar los primeros pasos de un Webscrapper a partir de los fundamentos del paradigma OO, que filtre y compare datos semejantes en diferentes páginas web, mejorando la eficiencia 
y recolección de datos a partir de la web*

**Visión**
  - Inspirar el desarrollo de soluciones automatizadas que impulsen la toma de decisiones basada en datos, promoviendo la curiosidad y el aprendizaje continuo en nuestra comunidad académica.
  - Consolidar un proyecto que permita extraer y organizar datos de manera sencilla, sirviendo como base para futuros proyectos académicos o profesionales en programación orientada a objetos.
**Misión**
  - Desarrollar un emulador de webscrapper capacitado para filtrar información y asignarlo en estructuras de datos comparables
  - Impulsar el crecimiento profesional de nuestro equipo.
