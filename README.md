# Proyecto Final: Webscrapper en Python 
> El presente es la documentación inicial que despegará el proyecto de generar un
> emulador de un sistema de webscraping basado en los principios de la POO

La gran disponibilidad de información es la gran ventaja de la sociedad actual,sin embargo, a su vez condiciona grandes desordenes 
e ineficiencia gracias a su abrumador contenido.

En estos casos la necesidad de un clasificador de datos visibles o no en la red se hace evidente, especialmente en aquellos casos donde buscamos
información muy específica y facilmente obtenible.

A partir de esto, nace a la luz el webscrapping, entendido cómo la *técnica automatizada para exraer y estructurar grandes cantidades de datos no estructurados, para su analísis*.
en servidores web.compuesto en tres procesos principales:

| proceso | descripción | 
|---------|-------------|
| Extracción de datos | petición de información al servidor usando el built-in "request" | 
| Organizar información | clasificar y dividir información para extraer solo la relevante, tambien llamado "parsear" datos |
| Procesar y Almacenar | busca dar un analisis específico a la información requerida, para luego almacenarla |

El webscrapping tiene cómo fin automatizar la busqueda ordenada de información grande, que determine procesos, resuelva problemas y lleve a cabo decisiónes 
a partir de esta.
